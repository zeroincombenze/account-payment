Questo modulo permette all'utente di eliminare una registrazione di pagamento.
Una registrazione di pagamento non può essere rimossa se la relativa registrazione
contabile ha già ricevuto il numero di protocollo.
Questo modulo azzera il campo "move_name" prima dell'eliminazione.

**Attenzione!** Questa azione genera un salto di numerazione contabile.
Questa situazione potrebbe essere invalidante per una contabilità fiscale.
