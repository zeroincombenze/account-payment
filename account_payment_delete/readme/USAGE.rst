|en|
In order to operate, you have to enable deleting entries in journal.
In developer mode, menu Invoicing > Configuration > Journals
choice the bank journal for pyament, on tab [Advanced Setting] enable
"Allow Cancelling Entries".

|it|
Per eliminare la registrazione è necessario abilitare l'eliminazione nel relativo
registro sezionale contabile.

In modalità sviluppatore, menù Fatturazione > Configurazione > Registri,
selezionare il registro bancario di pagamento, nella linguetta [Impostazioni Avanzate]
abilitare il campo "Consentire annullamwnto registrazioni".
